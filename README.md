# Full Control on ESP32

手元にない小さな基板を、ブラウザからどこでも操作できる仕組みです。

**[コントロールページを開く](https://esp32-remote-control.kd1454812.workers.dev)** ／ [English version](README.en.md)

## 1. 何の役に立つか

基板が家にあって、自分が外にいても、スマホやパソコンから操作できます。

- **LED** — 色を自由に指定(固定色だけでなくカラーホイールと明るさ)、全部または1個ずつ、時間を決めて自動で消灯。ランダム配色や一括消灯も。
- **サーボ** — 角度を指定、往復させる、ハンマーのように打つ、の3通り。
- **音** — 圧電スピーカーで任意の音、または内蔵の5曲。曲に合わせてLEDが光ります。
- **画面** — 基板のOLEDに気温・湿度・明るさを表示。「ディスプレイ」タブで文字を打つと、その場で実機の画面に出ます(左・中央・右揃え)。
- **見るのは自由、変えるにはPIN** — 今の状態(色、角度、曲、センサー値)は誰でも見られ、操作のときだけPINが要ります。
- **嘘をつかない表示** — 基板がオフラインのとき「送信済み」とは言わず「保留中 — デバイスがオフラインです」と出ます。再接続すると届きます。
- 電源はUSBだけ。ルーターのポート開放は不要です。

## 2. 使っている技術

- **基板** — MicroFan ESP32-C3M-TRY(4 MB)。ファームウェアは PlatformIO / Arduino C++(`src/`, `platformio.ini`)
- **通信** — MQTT over TLS、ブローカーは EMQX Cloud。基板は常時つなぎっぱなしで、コマンドを即反映し、自分の状態を配信し続けます
- **中継と配信** — Cloudflare Workers(`cloudflare/`)。ダッシュボードの配信とコマンドの受け渡しを担当します
- **画面** — HTML / CSS / JavaScript
- **部品** — AHT21(気温・湿度)、フォトトランジスタ(明るさ)、SSD1306 OLED、NeoPixel RGB LED、サーボ、圧電スピーカー
